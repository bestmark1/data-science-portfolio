# 06. Отзывы об отелях (Booking): EDA и бейзлайн RandomForest

Разведочный анализ датасета отзывов об отелях (Booking.com) и подготовка данных для модели `RandomForestRegressor`, предсказывающей рейтинг отеля по отзыву.

**Файл:** [`hotel_reviews_eda.ipynb`](hotel_reviews_eda.ipynb)

## Что сделано

1. **Очистка:** пропуски в координатах `lat`/`lng` заполнены медианой (чтобы не терять строки тестовой выборки), строковые признаки (например, `days_since_review`) переведены в числа.
2. **Feature engineering:**
   - сезонность (месяц и год отзыва);
   - бинарные флаги `is_no_negative` и `is_no_positive` (отсутствие жалоб или похвалы сильно связано с оценкой);
   - «истинная репутация отеля» через target encoding.
3. **Отбор признаков:** проверка значимости (`f_regression` / ANOVA), анализ мультиколлинеарности. Текстовые признаки переведены в числа.

## Результат

`RandomForestRegressor` (100 деревьев): **MAPE на валидации ≈ 13.59%**, то есть в среднем модель ошибается примерно на 1.3 балла из 10. Это бейзлайн без подбора гиперпараметров.
