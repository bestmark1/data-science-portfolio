# 10. Честная цена? — проверка цены квартиры в объявлении ⭐

**Код и полная документация:** [bestmark1/fair-price](https://github.com/bestmark1/fair-price)

Проект лежит в отдельном репозитории (пакет на Python, веб-сервис, Docker, тесты, CI), здесь — краткая карточка.

## Задача

Пользователь указывает квартиру на карте, её параметры и цену из объявления. Сервис называет рыночный диапазон, выносит вердикт (завышена / в рынке / подозрительно дёшево) и объясняет, из чего складывается оценка. Данные — [Russia Real Estate 2018–2021](https://www.kaggle.com/datasets/mrdaniilak/russia-real-estate-20182021) (Kaggle), 7 городов-миллионников, 1,6 млн объявлений после очистки.

## Что сделано

- Отбор городов по коду региона и радиусу от центра; исключение региона с аномалией выгрузки (Новосибирск)
- Очистка: повторные публикации, неправдоподобные площади, кухни и этажи; правила совпадают с валидацией API
- Разбиение по квартирам (с округлённым ключом), а не по строкам — без утечки через повторные объявления
- CatBoost P10 / P50 / P90 на log-цене + конформная калибровка интервала (CQR)
- Объяснение через TreeSHAP, сгруппированное в понятные факторы
- FastAPI + страница с картой (Leaflet), Docker, pytest, Ruff, GitHub Actions

## Результаты (отложенная выборка, 129 тыс. объявлений)

| Модель | MAE | MAPE |
|--------|-----|------|
| **CatBoost P50** | **0,67 млн ₽** | **11,0%** |
| Бейзлайн: медиана ₽/м² в городе × площадь | 1,39 млн ₽ | 20,9% |

Интервал P10–P90 покрывает 80,0% цен при цели 80% (по городам 79–81%). Главный фактор цены — расположение, затем площадь.

Проект начинался на учебном датасете курса, но там уровни цен между городами оказались неправдоподобными (квартира в Москве выходила дешевле, чем в Иркутске), поэтому данные заменены.
