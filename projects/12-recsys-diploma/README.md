# 12. Рекомендательная система для интернет-магазина - дипломный проект ⭐

**Код и полная документация:** [bestmark1/recsys-diploma](https://github.com/bestmark1/recsys-diploma)

Проект лежит в отдельном репозитории (подготовка данных, обучение, FastAPI-сервис, Docker и smoke-проверки), здесь - краткая карточка.

## Задача

Подобрать 3 товара для главной страницы интернет-магазина с учётом истории пользователя. Данные - Retailrocket: 2,76 млн событий, около 1,4 млн пользователей и 235 тыс. товаров, май-сентябрь 2015 года. Цель проекта - рекомендации для допродаж; качество оценивается офлайн по Precision@3 на покупках.

## Что сделано

- Очистка событий от дубликатов и ботов, подготовка свойств товаров с учётом времени их изменения
- Генерация кандидатов из истории пользователя, совместных просмотров и популярных товаров
- 45 признаков пользователя, товара и их взаимодействий; один и тот же код подготовки признаков при обучении и в сервисе
- Сравнение популярных товаров, эвристики, LightGBM binary и LightGBM LambdaRank; финальная модель ранжирует кандидатов с таргетом «корзина или покупка»
- Временная валидация: признаки по прошлым событиям, таргет по следующим 30 дням; гиперпараметры выбраны на validation, финальная оценка выполнена на отдельном test
- FastAPI: `GET /recommend`, `POST /recommend`, `/health`, `/metrics`; популярные товары для пользователей без истории и при ошибке модели
- Docker, валидация запросов, метрики Prometheus и smoke-проверки API

## Результаты (test, 18.08-18.09.2015)

Precision@3 считается по покупкам: число купленных товаров среди трёх рекомендаций, делённое на 3. Среднее рассчитано по 2 484 покупателям тестового периода; отдельно - по 349 покупателям с историей до даты среза.

| Подход | Precision@3: все покупатели | Precision@3: покупатели с историей |
|--------|----------------------------|-----------------------------------|
| **LightGBM LambdaRank** | **0,0160** | **0,0783** |
| Эвристика | 0,0150 | 0,0716 |
| Популярное за последние 3 дня (fallback) | 0,0071 | 0,0153 |
| Baseline: общий топ-3 за весь train | 0,0099 | 0,0172 |

## Ограничения

- Около 86% покупателей теста не имели истории до даты среза: для них используется fallback. На test популярное за 3 дня оказалось хуже общего топа, хотя на validation было лучше.
- Полнота кандидатов для пользователей с историей составляет около 13-15%, что ограничивает качество итоговой выдачи.
- Результаты получены офлайн. Влияние рекомендаций на реальные допродажи и оборот нужно проверять A/B-тестом.
- История и таблицы признаков в сервисе статичны; для работы на новых данных нужен регулярный пересчёт.
