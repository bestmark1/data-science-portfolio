# 02. Прогнозирование продаж: временные ряды ⭐

Прогноз продаж на данных [Corporación Favorita Grocery Sales Forecasting](https://www.kaggle.com/competitions/favorita-grocery-sales-forecasting) (Kaggle, сеть магазинов Эквадора): от классической декомпозиции ряда до градиентного бустинга.

**Файлы:** [`sales_forecasting_project.ipynb`](sales_forecasting_project.ipynb) (выполнен целиком, с выводом и графиками) · [`data/holidays_events.csv`](data/holidays_events.csv)

## Содержание

1. **Магазин №25 — базовый анализ ряда.** Чтение `train.csv` по частям (файл ~5 ГБ, 125 млн строк), сезонная декомпозиция, тест Дики-Фуллера, `TimeSeriesSplit`, скользящие статистики (среднее, стандартное отклонение, линии Боллинджера, EMA), лаговые признаки.
2. **Товар №103501 — ARMA/ARIMA.** Тест Дики-Фуллера, скользящее среднее, лаги 1–6, линейная регрессия на лагах, параметры `p`/`q` по ACF/PACF, ARIMA. Сравнение MSE, MAE, MAPE.
3. **Общий объём продаж — Prophet.** Прогноз на 365 дней, подбор `changepoint_prior_scale`, месячная сезонность, праздники. Сравнение RMSE на каждом шаге.
4. **Общий объём продаж — XGBoost и CatBoost.** Календарные признаки, признак праздника (библиотека `holidays`, Эквадор), лаги с ограничением «лаг ≥ размер тестовой выборки». Сравнение MSE, MAE, MAPE.

## Ключевые результаты

- Тест Дики-Фуллера подтвердил стационарность рядов и для магазина №25, и для товара №103501.
- В Prophet больше всего точности дало добавление **праздников** (RMSE снизился с ≈109 тыс. до ≈74 тыс.), а не тонкая настройка `changepoint_prior_scale` или сезонности.
- В XGBoost/CatBoost праздники тоже оказались самым полезным признаком; лаги ≥30 дней (не меньше горизонта прогноза) немного ухудшили метрики обеих моделей.
- CatBoost на «сырых» календарных признаках без настройки точнее XGBoost.

## Данные

- `train.csv` (~5 ГБ) **не входит в репозиторий**. Скачайте его со страницы [соревнования на Kaggle](https://www.kaggle.com/competitions/favorita-grocery-sales-forecasting/data) и положите рядом с ноутбуком. Без него ноутбук не запустится, но все результаты сохранены в его выводе.
- `data/holidays_events.csv` — календарь праздников Эквадора (входит в репозиторий).

## Запуск

```bash
pip install -r requirements.txt
jupyter notebook sales_forecasting_project.ipynb
```

Полный прогон занимает около 3 минут, для чтения `train.csv` по частям хватает 16 ГБ RAM. Версии в `requirements.txt` закреплены точно; `prophet` может потребовать отдельной установки на Apple Silicon.
