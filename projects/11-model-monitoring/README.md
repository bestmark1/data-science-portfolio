# 11. Мониторинг ML-модели: Prometheus + Grafana ⭐

**Код и полная документация:** [bestmark1/model-monitoring](https://github.com/bestmark1/model-monitoring) · **Демо-дашборд:** [bestmark1.github.io/model-monitoring](https://bestmark1.github.io/model-monitoring/)

Проект лежит в отдельном репозитории (сервис модели, Prometheus, Grafana, Docker Compose, тесты, CI), здесь — краткая карточка.

## Задача

Поставить модель в сервис и наблюдать за ней в работе: качество, дообучение, дрейф данных, нагрузка. Модель предсказывает, вырастет ли цена на электроэнергию относительно среднего за сутки. Данные — [Electricity (Elec2)](https://www.openml.org/d/151): 45 312 получасовых записей рынка Нового Южного Уэльса (Австралия), 1996–1998. Классический датасет для моделей на потоке со сдвигом распределения.

## Что сделано

- Модель `SGDClassifier` + `StandardScaler`, которую можно дообучать через `partial_fit`: автоматически каждые 1000 размеченных примеров или вручную `POST /retrain`; каждая версия сохраняется
- Сервис на FastAPI: `/predict`, `/feedback` (истинный ответ), `/retrain`, `/metrics` для Prometheus
- Метрики: accuracy, F1 и log loss на скользящем окне, ошибки, распределение прогнозов, версия модели и длительность дообучения, PSI-дрейф каждого признака, задержка и нагрузка
- Контрольная модель: первая версия работает рядом с дообучаемой на тех же запросах, поэтому выигрыш от дообучения измеряется
- Grafana с источником данных и дашбордом из provisioning (18 панелей), алерты Prometheus
- Симулятор проигрывает поток в хронологическом порядке; весь стек поднимается через `docker compose up`

## Результаты (поток из 40 312 примеров, 40 дообучений)

| Модель | Accuracy по потоку |
|--------|--------------------|
| **Дообучаемая** | **74,8%** |
| Первая версия без дообучения | 70,1% |
| Всегда угадывать частый класс | 57,1% |

Дрейф на дашборде объясняет разницу: в обучающих данных признаки рынка Виктории были константой-заглушкой, а примерно с 12-тысячного примера в потоке появляются реальные значения (PSI > 3). Замороженная модель этого не учитывает.
