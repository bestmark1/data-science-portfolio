# Analysis of Vacancies from HeadHunter

SQL-анализ базы данных вакансий HeadHunter: регионы, работодатели, отрасли и рынок труда дата-сайентистов.

## Описание проекта

Проект представляет собой исследование рынка труда на основе базы данных hh.ru. Анализ выполнен с использованием SQL-запросов через Python (psycopg2 + pandas).

## Структура базы данных

- **vacancies** — вакансии (название, зарплата, опыт, график, ключевые навыки)
- **employers** — работодатели
- **areas** — регионы
- **industries** — сферы деятельности
- **employers_industries** — связь работодателей и сфер деятельности

## Содержание анализа

### 1. Предварительный анализ
- Общее количество вакансий, работодателей, регионов и сфер деятельности

### 2. Детальный анализ вакансий
- Зарплатная вилка по всем вакансиям
- Распределение по графику работы и типу занятости
- Распределение по требуемому опыту
- Топ регионов по количеству вакансий

### 3. Анализ работодателей
- Топ работодателей по количеству вакансий
- География найма работодателей
- Анализ сфер деятельности
- Вакансии Яндекса в городах-миллионниках

### 4. Предметный анализ (Data Science)
- Количество DS-вакансий и вакансий для junior-специалистов
- Популярность Python и SQL среди требований
- Среднее количество ключевых навыков
- Средняя зарплата по уровням опыта

## Ключевые выводы

- База содержит **49 197 вакансий** от **23 501 работодателя** в **1 362 регионах**
- Лидер по вакансиям — **Яндекс** (1 933 вакансии в 181 регионе)
- Средняя зарплатная вилка: **71 065 — 110 537 руб.**
- Для дата-сайентистов доступно **1 771 вакансия**, из них **51** — для junior
- DS с опытом 3–6 лет может рассчитывать на **243 115 руб.**
