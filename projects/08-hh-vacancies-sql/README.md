# 08. SQL-анализ вакансий hh.ru

Исследование рынка труда по базе вакансий HeadHunter: регионы, работодатели, отрасли и вакансии для дата-сайентистов. SQL-запросы к PostgreSQL выполняются из Python (`psycopg2` + `pandas`).

**Файл:** [`hh_vacancies_sql.ipynb`](hh_vacancies_sql.ipynb)

## Структура базы

- `vacancies` — вакансии (название, зарплата, опыт, график, ключевые навыки)
- `employers` — работодатели
- `areas` — регионы
- `industries` — сферы деятельности
- `employers_industries` — связь работодателей и сфер

## Содержание анализа

1. **Предварительный анализ:** число вакансий, работодателей, регионов и сфер деятельности.
2. **Вакансии:** зарплатная вилка, график и тип занятости, требуемый опыт, топ регионов.
3. **Работодатели:** топ по числу вакансий, география найма, сферы деятельности, вакансии Яндекса в городах-миллионниках.
4. **Data Science:** число DS-вакансий и вакансий для junior, популярность Python и SQL, среднее число ключевых навыков, средняя зарплата по уровням опыта.

## Ключевые выводы

- В базе **49 197 вакансий**, **23 501 работодатель**, **1 362 региона**.
- Лидер по вакансиям — **Яндекс** (1 933 вакансии в 181 регионе).
- Средняя зарплатная вилка: **71 065 – 110 537 руб.**
- Для дата-сайентистов открыто **1 771 вакансия**, из них **51** — для junior.
- DS с опытом 3–6 лет: в среднем **243 115 руб.**

## База данных и запуск

База (учебный дамп hh.ru) не входит в репозиторий, а параметры подключения (`DBNAME`, `USER`, `HOST`, `PASSWORD`, `PORT`) в ноутбуке намеренно не заданы: перед запуском определите их сами, например через переменные окружения, и не коммитьте пароли. Без базы ноутбук не запустится, но результаты сохранены в его выводе.

```bash
pip install pandas psycopg2-binary jupyter
jupyter notebook hh_vacancies_sql.ipynb
```
